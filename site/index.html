Getting started

From download to workspace.

  1. Choose the installer for your operating system.
  2. On Windows, run the installer. On Mac, open the DMG and drag PulseForge to Applications. On Linux, install the DEB or run the AppImage.
  3. Explore demo and paper controls, then configure your own provider keys for live market data.

Before you trade

Live trading uses real funds and can lose money. Windows live signing starts disarmed; importing a wallet does not activate trading. The model is an uncalibrated baseline, not a profit guarantee.
