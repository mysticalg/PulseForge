Start locally

  1. Download and run the Windows installer.
  2. Open PulseForge and explore the demo and paper-trading controls.
  3. For live market data, configure your own provider keys using the setup guide.

This website provides downloads and documentation. The app runs on your computer.

What’s inside

  • Market scanning, transparent strategy settings and automatic paper entries and exits.
  • Persistent paper positions, portfolio controls and configurable risk limits.
  • Separate live wallet sessions with explicit activation and a confirmed-fill journal.

Before you trade

Live trading uses real funds and can lose money. Live signing starts disarmed; importing a wallet does not activate trading. Read the live wallet guide before activation. The bundled model is an uncalibrated baseline, not a profit guarantee. The installer is unsigned.
